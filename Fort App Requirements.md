Version:1

Date: 28-9-2026

Project Overview:

This document defines the functional and technical requirements for the Android mobile application to monitor and manage smart door locks and door sensors.

Requirements:

Modify the existing ‘NOVA’ mobile application with a new package name and related configurations to create the new App – ‘FORT’

The FORT app will have a new server and DB 

After the lock is added to the account and the lock details page is updated (This happens only once - After the lock is engaged for the first time after add lock procedure)

Hide the existing icons/functionality for

Passage mode, PINs, RFID, Users, Engage lock, Remote Access

Show icons/functionality for

Fingerprint, History, OTP, Battery Level, Wi-Fi Configuration

In-App notification when OTP is generated by the user at the lock

In the App dashboard, add a new tab for sensors

Similar functionality to Lock

Can add new sensors to the list using sensor name and code 

Can view the list of all the sensors added to the account

When a sensor is selected from the list – open the sensor details page, 

Display – Sensor name, Sensor Wi-Fi Configuration, History, Battery Level

The remaining auxiliary functions like factory reset, etc. (but not limited to) that are available for the lock should also work for the door sensor.
